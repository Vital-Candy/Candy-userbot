# История изменений

## 2.3.0
- Магазин плагинов `.store`: список, `info`, `install`, `update`, `remove`. Плагины лежат в репозитории в `store/plugins/`, список с версиями и SHA-256 в `store/index.json`. Установка только по вашей команде и после `--yes`, файл ставится, лишь если сумма, размер и метаданные совпали с индексом и код компилируется; при сбое загрузки прежнее состояние возвращается. Чужой файл с тем же именем не затирается, изменённый вами заменяется только с `--force`.
- Плагины отдельно от юзербота: `store/` не устанавливается ни `installer.sh` (sparse-checkout), ни `.update`, а `plugins/` в репозитории пуста (пример `example` переехал в `store/plugins/example.py`; его ставит `.store install example`).
- `tools/build_store_index.py` и `tools/publish.sh`: индекс магазина пересобирается при публикации, сломанный плагин или чужие файлы в `plugins/` блокируют публикацию.
- `PluginManager.forget(имя)`: убирает выгруженный плагин с удалённым файлом из реестра (нужно `.store remove`).

## 2.2.0
- `.tag` отправляет все отметки одним сообщением и делит их, только когда не помещаются в предел Telegram (3900 символов или 90 ссылок на аккаунт без username); между частями пауза 1.5 с.
- Паузы между командами чужих людей теперь у всех уровней и зависят от ранга: user 5 с, trusted 3 с, admin 1 с (нулевой нет даже у admin, минимум 0.5 с, владельцу пауза не нужна). Тяжёлые команды умножают паузу на вес: `.ping` и `.user` x2, `.status` x3, `.tag` x20.
- `.perm cooldown`: показать паузы и веса, задать базовую паузу уровня (только владелец, 0.5 до 3600 с, user ≥ trusted ≥ admin), `reset`. Настройки в базе, `.update` их не сбрасывает; видны в `.perm audit`.
- Тот, у кого есть право на команду, но кто написал слишком рано, получает один ответ «Подождите N с» (дальше молчание); остальные паузу молча не обходят.
- Убрана отдельная пауза `.tag` (60 с): её заменила общая система с весом.
- API: `register_command(..., pause=вес)`.

## 2.1.0
- `.perm audit [N]`: сводка прав (сколько людей на каком уровне), команды, открытые шире обычного, подозрительные места (несколько уровней, выдал человек без прав, настройки для исчезнувших команд) и журнал последних изменений (кто, когда, что; до 100 записей).
- `.perm cmd` стал удобнее: пронумерованная таблица, несколько команд сразу, номера вместо имён, `all`, `off` (то же, что `owner`); при ошибке в одном имени не меняется ничего.
- `.perm` нельзя опустить ниже admin, а для низких уровней он не работает, даже если его открыли по ошибке.
- `.tag` для чужих: пауза 60 секунд между запусками одного человека.
- Исправлено: два сообщения подряд от одного человека могли пройти мимо паузы.
- `tools/publish.sh`: одна рабочая папка `~/.candy-publish` (удаляется после отправки, старые `candy-publish-*` убираются), файл запретных слов проверяется до скачивания, новые проверки (телефоны, `api_id`, личные файлы) и автоматические запретные слова из `git config` и профиля GitHub.
- Убраны неиспользуемые импорты.

## 2.0.0
- Новая иерархия прав: `user` < `trusted` < `admin` < `owner`. Владелец (сам аккаунт) ни на что не завязан; тем, кому уровень не выдан, команды молча игнорируются. Команды открываются другим только если зарегистрированы с `level`; переключение аккаунтов, обновление, перезапуск, бэкап, плагины и префикс не открываются никому.
- `.user`, `.status`, `.tag` для чужих показывают урезанный вид (без телефона, имени из контактов, общих чатов, внутренностей); `.ping` и `.help` доступны уровню `user`, `.help` показывает только доступное.
- `.perm cmd`: уровни команд меняются вручную и хранятся в базе, `.update` их не сбрасывает; `.perm cmd reset`. admin управляет только `user` и `trusted`.
- `.mute --all` больше не удаляет ваши сообщения; флаги `-user`, `-trusted`, `-admin` оставляют право писать тем, у кого есть этот уровень или выше; без флага пишет только владелец.
- Внимание: выданные раньше `admin` теперь имеют реальные (ограниченные) права.

## 1.9.0
- `.mute [длительность] [--all]`: режим тихого удаления новых сообщений (личный чат, группа, `--all` с двойным подтверждением, ответом на сообщение пользователя), остановка ответом `stop`, `.mute off`, `.mute list`, возобновление после перезапуска.

## 1.8.0
- `.purge <N> [all]`: тихое удаление ровно N последних сообщений; `all` требует прав на удаление.
- `.setprefix`: смена префикса команд, хранится для каждого аккаунта; `.help` показывает новый префикс.

## 1.7.0
- Команда `.dd` удалена (вместе с переменной `CANDY_DOWNLOADS_DIR`).

## 1.6.1
- `tools/publish.sh` отказывается работать из рабочей установки (где есть сессия Telegram): выпуск готовится в отдельной папке, а на устройство ставится только командой `.update`. Обойти: `PUBLISH_FROM_INSTALL=1`.

## 1.6.0

## 1.5.0
